# Roleplay

从 PNG 角色卡加载角色提示词，支持可选的视觉自我参照。

## 视觉自我参照（默认关闭）

在 Koishi 的 `yesimbot-roleplay` 插件设置中，开启“角色视觉自我参照”，并填写一张本地参考图的路径：

```yaml
characterCard: data/roleplay/character.png
enableVisualReference: true
visualReferenceImage: data/roleplay/reference.jpg
```

- 支持 PNG、JPEG、WebP，最多 5 MiB；按文件内容识别格式，不依赖扩展名。相对路径以 Koishi 工作目录为起点。
- 参考图独立于 PNG 角色卡封面，不修改原卡的文字数据。没有开启时，不读取参考图路径，也不改变原有角色卡行为。
- 开启后，system 的角色段说明图片的身份归属，原图字节作为固定多模态前缀出现在真实对话前。它不是每轮末尾提醒，也不是用户的新消息；图中服装不被视为所有场景的固定穿着。
- 参考图不会自动发送给聊天对象，也不会作为消息写入聊天记录或压缩原文。与其他输入一样，它仍可能影响角色之后的真实回答；不保证模型一定理解或长期遵循。
- **主模型必须支持原生图片输入**。本功能不调用辅助模型，不把图片改写成外貌描述，也不在运行时下载外链。URL 或放在文字中的 Base64 不能代替图片文件。
- 每次主模型请求仍会携带这份固定背景，增加视觉 token 开销。稳定前缀可能有利于提供方缓存，但不保证缓存命中或费用减免。
- 开启时路径为空、文件无法读取、格式不支持或超过大小限制，会明确报错，不静默退回纯文字。
- 图片在插件启动时读取并缓存。修改开关、路径或图片内容后，按 Koishi 正常流程重启／重建该插件；不支持仅编辑文件即热更新。关闭后重建插件即可恢复原有行为。

参考图和私人角色卡属于部署数据，应存放在私有目录，不要随通用源码发布。
